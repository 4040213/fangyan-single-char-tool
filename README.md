# 方言单字声韵调自动填写工具（fangyan_tool.html）

[![GitHub](https://img.shields.io/badge/GitHub-4040213%2Ffangyan--single--char--tool-blue?logo=github)](https://github.com/4040213/fangyan-single-char-tool)
[![License: 仅供学术使用](https://img.shields.io/badge/license-学术使用-green)](#)
[![单文件 · 零依赖](https://img.shields.io/badge/tool-单文件%20零依赖-orange)](fangyan_tool.html)

为《方言调查字表》式方言调查点，自动推断并填写家乡方言 **3810** 个单字的**声母 / 韵母 / 声调**而设计的单文件 Web 工具。
基于南科大 FYCL 方言处理系统的标准字表（`data/index.json`）与中古音分类，按"同中古类同现代音"假设批量推断，并提供抽样校验、全字审核与修改历史功能。

> **在线使用**：直接用浏览器打开本仓库的 [`fangyan_tool.html`](fangyan_tool.html) 即可（也可访问 GitHub 仓库页面下载）。工具零依赖、零后端：所有数据保存在浏览器本地（localStorage）与导出的文件里。

## 一、它能做什么

| 模块 | 功能 |
|---|---|
| **声母 / 韵母 / 声调表** | 按中古音分组（声 **59** 类 / 韵 **138** 类 / 调 **8** 类）填例字，工具自动把例字音应用到同组全部字 |
| **音标面板** | 222 个 IPA 国际音标（辅音 / 元音韵尾 / 声调），随表自动切换；支持点选插入 |
| **结果预览** | 3810 字逐字显示中古音 + 推演方言音，可搜索 |
| **语音系统汇总** | 由你填的读音自动去重生成方言声韵调系统 |
| **质检 · 正确率** | 记号体系检查（IPA vs 系统原字形）、漏填类提示、覆盖率与估算正确率 |
| **抽样校验** | 按中古类分层抽样，你填真实音后算出**推演值 vs 真实值的真实误差率**（声/韵/调分别统计）；再次抽样只追加**未抽过且不在安全区**的字，新字标「新·待判定」 |
| **全字审核** | 逐字查看 / 修改 3810 字推演音，每次修改记录**原生成音、修改后音、时间、来源**，可回溯导出 |
| **自动保存** | 每次输入自动写浏览器本地，重新打开自动读回；也可手动下载 `方言草稿.json` 实体备份 |
| **导入 / 导出** | 可载入自己方言点的 `index.json`；导出填好的 `index_filled.json`（可回灌 FYCL 系统）+ CSV 底稿 |
| **《方言调查字表》标准三表** | 按传统方言学规范生成**声母表 / 韵母表 / 声调表**（声类→声母、中古韵→韵母的科学定类，自动标注洪细与⚠提示），一键导出 CSV |
| **音系规律** | 跨组合流检测、声韵配合矩阵、记音一致性检查（IPA vs 系统字形）、最小对立 / 互补分布自动判定（含置信度分级） |
| **抽样校验 · 安全区** | 已校对并提交的字自动进入「安全区」，下次抽样不再出现；「已验证字」面板可查看安全区全部已校字并「移回重校」（原逐字修正保留）；提交前强制三项完整判定，缺漏会逐条列出并**阻止提交** |

## 二、为什么能"自动填写"

核心假设：**同一个中古分组（声 + 韵 + 调 + 等 + 呼 + 平仄）的字，在现代方言里往往同音**。
因此你只需为每类中古分组填**一个例字**的读音，工具就把这个读音复制给该组下所有字。

- 分组维度（已结合音韵学细分，见 §2.1）：
  - **声母 59 类** = 中古声母 40 类，其中**全浊母按平/仄拆两类**（清化"平送仄不送"）。
  - **韵母 138 类** = 中古韵母 95 类 × **开合口 × 等**（同韵因开合/等不同而读不同韵母）。
  - **声调 8 类** = 中古调类（平上去入）× 清浊（已含"平分阴阳"）。
  - 共 **205 个判断**即可覆盖全表 3810 字。
- 推断按三维独立分组实现，已实测零缺失覆盖。

### 2.1 分组维度怎么定（音韵学依据）

| 表 | 分组 key | 行数 | 音韵学依据 |
|---|---|---|---|
| **声母** | 中古声母；**全浊母再按平/仄拆**；**腭化/尖团敏感母（見溪羣曉匣精清從心邪）再按洪/细（等）拆** | 40 → 71 | 全浊清化"平送仄不送"（並母平 pʰ/仄 p）；见组细音腭化、精组尖团使同声母洪细读不同声母，按洪(一/二等)/细(三/四等)拆开。清母及次浊母（明微泥来娘日）原本一母一音，不拆。 |
| **韵母** | 中古韵母 × **开合口(HU)** × **等(DENG)** | 95 → 138 | 同中古韵因开合口（主元音/韵头 u 不同）与等第（二等无 i 介音、三等多 i 介音）读成不同韵母。例：麻韵 開二=a / 開三=ia / 合二=ua。 |
| **声调** | 中古调类(平上去入) × **清浊(QZ)** | 8（不变） | 已覆盖"平分阴阳""全浊上变去""入声派调"。无需改结构，只需按规律填写（见 §3.5）。 |

> 说明：见组（见溪羣晓匣）细音腭化（读 tɕ 系）、精组尖团是西南官话常见分化，已通过 **v3 声母×等呼细分**处理——見溪羣曉匣精清從心邪 按洪(一/二等)/细(三/四等)拆为不同行。若个别字仍有特例（如二等腭化），用「全字审核」逐字修正。

> **精度边界（务必阅读）**：分组已纳入等/呼/平仄，且 v3 已拆分见组腭化与精组尖团（洪/细），绝大多数系统性分化已处理；**残余误差主要来自个别方言更细的音变**（如二等腭化、特定字的例外音变）。**真实误差只能用「抽样校验」模块由你人来核定**——工具无法知道你家乡话到底怎么读。

## 三、使用方法

### 1. 打开工具
直接用浏览器（Chrome / Edge / Firefox 均可）打开 `fangyan_tool.html`。

### 2. 载入你自己的方言点（可选但推荐）
系统自带的 `data/index.json` 是**贵州大方样例**骨架。若你已从 FYCL 系统导出自己方言点的 `index.json`：
- 点工具里的「载入我的 index.json」按钮选择文件，即可替换字表与中古音数据（方言字段留空待填）。

### 3. 填例字（核心步骤）
- 切到「声母表 / 韵母表 / 声调表」三个 tab；
- 每类中古类有一个输入框，用左侧音标面板点选 IPA 填入例字音；
- 声调支持键盘自由输数字（如 `55` `213`），入声可加喉塞标注（如 `5ʔ`）；
- 例字可点击切换（避免生僻字做代表字）。

### 3.5 声调表怎么填（西南官话·大方点参考）

声调表已按「中古调类 × 清浊」分成 **8 类**，正好对应音韵学演变规律。以贵州大方（西南官话黔北片）为例，按以下规则填：

| 中古调类 | 清浊 | 方言演变 | 填写示例（调值） |
|---|---|---|---|
| 平 | 清 | → 阴平 | 55（高平） |
| 平 | 浊 | → 阳平（平分阴阳） | 21（低降） |
| 上 | 清 / 次浊 | → 上声 | 53（高降） |
| 上 | 浊 | → 去声（**全浊上变去**） | 同去声调值 |
| 去 | 清 | → 阴去 | 如 24（按实际） |
| 去 | 浊 | → 阳去 | 如 213（按实际） |
| 入 | 清 / 浊 | 西南官话**入声派阳平** | 同阳平（可标 `21`，或 `21ʔ` 提示原促声） |

> 要点：**全浊上声**那一行要填"去声"调值（不是上声）；**入声**两行在西南官话多并入阳平。具体调值以你方言点实际为准，上表数字仅作大方点示例。

### 4. 查看推断结果
切到「结果预览」看 3810 字逐字推演音；「语音系统汇总」看去重后的方言音系。

### 5. 抽样校验（算真实误差）
- 切到「抽样校验」；
- 选样本量（30 / 50 / 80 / 120 / 200），点「生成抽样表」；
- 表中每行给出工具推演音，**你在"真实声/韵/调"列填入家乡话实际读音**；
- 点「计算误差」，得到整体正确率 + 分声/韵/调正确率 + 错得最多的中古类；
- 「导出校验表」可下载 CSV 继续填。

#### 5.1 安全区与「已验证字」面板（推荐流程）
- **提交即进安全区**：在抽样表里把某字的**声/韵/调三项都判定**（✓ 一致，或 ✗ 并填正确音）后点「提交校验结果」，这些字自动进入「安全区」。**安全区里的字下次抽样不再出现**，避免重复劳动。
- **提交前强制完整**：若有字没判定完、或标了 ✗ 没填正确音，提交会被**阻止**并逐条列出缺漏（如「保(声缺)」「泌(韵✗未填音)」），必须校对完整才能提交。
- **只自动保存、不强制导出**：提交仅自动写浏览器本地；要落实体文件点「保存草稿」（含安全区）或「导出校验表」（CSV）。
- **已验证字面板**：抽样校验页顶部的「已验证字 N ▾」按钮，展开后列出安全区全部已校字（中古音 + 已校声/韵/调），并带「移回重校」按钮——点它会把该字拉回上方校验表重新查看/修改（**原逐字修正保留**，改完再提交即可）。
- **继续抽样**：提交后点「生成抽样表」只抽没抽过、且不在安全区的新字，循环即可逐步覆盖全表。
- **数据持久**：安全区随 `verifyData.safe` 存入 localStorage（自动保存）与「保存草稿」下载的 `方言草稿.json`；重新打开或导入草稿后安全区一并恢复。

### 6. 全字审核与修改历史
- 切到「全字审核」；
- 可按汉字 / 中古类 / 推演音搜索，过滤"仅已修改 / 仅未推断"；
- 直接改某字的声/韵/调，保存即生效（覆盖例字表推断值）；
- 每次修改自动记录历史（原生成音 → 修改后音、时间、来源：审核修改 / 抽样校验回填）；
- 「查看修改历史」「导出历史」可回溯。

### 7. 导出回灌系统
- 「导出填好的 index.json」生成 `index_filled.json`；
- 用 FYCL 系统自带的导入器（`FYImportor`）读该文件写回 Derby 数据库即可。

## 四、数据管线与字段对齐（权威）

- **数据源**：`data/index.json`（3810 字，《方言调查字表》标准表，`LRZDBH="3810"`）。
- **系统导入器**：`lib/FYCL.jar` 内 `com/minibean/fycl/server/FYImportor` 读 `/index.json`(UTF-8) 经 `JSONDecoder` 写 Derby 库 —— **官方导入路径，字段 100% 对齐**。
- **单字表 `FYCL.DCSJ` 必填字段**：`FY_SHENG` / `FY_YUN` / `FY_DIAO`（你只需填这三个，与系统同名对齐）；其余中古音字段系统预置。
- **音系三表 `FYCL.FYSM` / `FYYM` / `FYDIAO`**：来自 `index.json` 的 `sms` / `yms` / `diaos`，工具导出时已用你家去重 IPA 重建 `mc` 字段。
- **建档表 `FYCL.FY`（方言点主表）、`FYCL.HZR`（合作人）**：在系统 GUI 新建方言点时填，不在 3810 字流程内。

## 五、记号体系说明（已知限制）

- 工具填的音是 **IPA 国际音标**；系统原有样例值用的是 **PUA 私有区字形**（非 IPA）。
- 「质检 · 正确率」面板会检测此差异并提示。导出数据**格式合法、可被系统读取**，仅显示层可能因字体不统一而观感不一致。
- **IPA → 系统字形校准**为可选增强步骤，不影响数据正确性与导入。

## 八、技术实现要点

- 纯前端单文件：HTML + CSS + 原生 JavaScript，内嵌字表数据，无任何外部依赖与网络请求。
- 推断引擎：`infer()` 按中古声（全浊分平仄 + 等呼洪细细分）/ 韵（开合+等）/ 调（清浊）三维映射，输出 3810 行 `{chr, ms, my, md, mqz, fs, fy, fd}`。
- 逐字覆盖层：`wordOverride[字hex] = {s, y, d, hist[]}`，优先级高于例字表推断，承载审核修改与历史。
- 抽样校验：按 `(声,韵,调)` 三元组分层抽样，保证覆盖各类；误差 = 推演音 vs 你填真实音的逐项比对。
- 持久化：`fangyan_draft`（localStorage，含 maps / liZi / wordOverride / verifyData / 时间戳 / `ver` 草稿结构版本）。

### v4（历史）— 标准三表 + 音系规律 + 易用性修复
- **《方言调查字表》标准三表（新增 `sec-std3` tab）**：按传统方言学规范生成**声母表 / 韵母表 / 声调表**，实现声类→声母、中古韵→韵母的科学定类；洪细按韵环境自动判定并标注⚠，支持手动拆分；一键导出 CSV。

- **拆分框 IPA 输入修复**：拆分输入框现在能正常接收底部音标面板与就地浮动面板插入的国际音标。
- **导入加固**：草稿文件导入改为完整恢复（声/韵/调 + 拆分 + 逐字修改）；"载入 index.json"按钮增加防呆，误选草稿文件会拒绝并提示，避免清空已填数据。
- **草稿兼容**：`DRAFT_VERSION` 升至 **4**。

### v3 — 声母等呼细分（结合音韵学再评估）

- **草稿兼容**：`DRAFT_VERSION` 升至 **3**；载入 v2 及更早草稿时自动清空声韵表填写（保留逐字修改历史与抽样数据），并提示按新分组重新填写。

### v2 — 分组结构升级（结合音韵学重新评估）
- **声母表**：由 40 类改为 **61 类**——全浊声母（並/定/羣/澄/从/邪/崇/船/禅/奉等）按**平/仄**拆两类，纠正"全浊清化平送仄不送"被一刀切的错误。

- **声调表**：保持 **8 类**（中古调类 × 清浊），结构本就正确，仅补 §3.5 填写指南（平分阴阳 / 全浊上变去 / 入声派调）。
- **草稿兼容**：引入 `DRAFT_VERSION=2`；载入 v1 旧草稿时自动清空声韵表填写（保留逐字修改历史与抽样数据），并提示按新分组重新填写。
- 总判断数 143 → **207**。
